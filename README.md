# Budget Balance Game

An interactive financial management game that teaches real-world budget skills through gamification. Make monthly financial decisions, track every choice, earn achievements, and receive personalized reports.

**[Play the Game](https://saharhalili95.github.io/budget-balance-game/)**

## Features

### Progression and Challenges
- **5 Progression Levels** - Advance from Student to Financial Expert as your financial skills grow
- **8 Achievements** - Unlock milestones like "First Saver" and "Budget Master" with full tracking
- **Monthly Challenges** - Time-limited goals that push your decision-making under realistic constraints

### Analytics and Reporting
- **Comprehensive Financial Reports** - Tracks income, expenses, savings rate, and spending patterns over time
- **Real-Time Analytics** - Live feedback and personalized recommendations based on your decisions
- **Decision Tracking** - Every financial choice is recorded and factored into your progress

### Experience
- **Bilingual Support** - Full English and Hebrew interface with proper RTL layout
- **Responsive Design** - Playable on desktop and mobile
- **Modern Animations** - Smooth transitions and visual feedback throughout
- **Local Storage Persistence** - Progress saved in the browser, no account required

## Tech Stack

| Layer | Technology |
|---|---|
| Frontend | React + TypeScript |
| Build Tool | Vite |
| Persistence | Browser Local Storage |
| Deployment | GitHub Pages |

## Getting Started

```bash
npm install
npm run dev
```

Open `http://localhost:5173` in your browser.
